# Elite Aggregate Services LLC — Website

Static one-page site for GitHub Pages.

## Files
- `index.html` — the entire site (HTML + CSS + JS inline)
- `logo.png` — transparent logo
- `.nojekyll` — tells GitHub Pages to serve files as-is

## Fonts
The proprietary logo fonts aren't freely licensed, so the site uses the closest Google Font matches:
- **Great Vibes** — for the "Elite" script
- **Saira Condensed** (heavy italic) — for the AGGREGATE / SERVICES headings

## Deploy to GitHub Pages
1. Create a new repo (e.g. `elite-aggregate-site`).
2. Upload these files to the repo root.
3. Repo **Settings → Pages → Source → Deploy from a branch**.
4. Branch: `main`, folder: `/ (root)`. Save.
5. Site publishes at `https://<username>.github.io/elite-aggregate-site/` in ~1 min.

For a custom domain (e.g. eliteaggregate.com), add it under Settings → Pages → Custom domain.
